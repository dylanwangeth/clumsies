External memory for coding agents

Give your agents a memory that belongs to the team.

clumsies keeps the rules, constraints, and project context that shape how agents write code outside any single agent runtime — organized, reviewed, and shared across your organization.

Download for macOS Read the docs View on GitHub

One Memory model

Rules, workflows, and project context are one Markdown-backed Memory object with a semantic description, stable IDs, and organization or project scope — not three closed types.

Automatic drafts

Desktop and MCP write to the same always-on daemon; local changes synchronize without a manual push step.

Reviewed authority

Drafts become authoritative only through review and a Commit that advances the organization or project Ref.

Agent-native Kanban

Agents claim and advance native Issues through typed kanban operations; only the user's Approve gate makes an Issue Done.

Host adapters

Codex, Claude Code, opencode, and the DeepSeek Harness share one App-bundled Rust runtime with release-identity checks.

Self-hosted Server

Run the Rust authority service and PostgreSQL in your own infrastructure with organization OIDC.
