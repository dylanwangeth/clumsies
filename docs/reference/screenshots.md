# Screenshot List

## Placement

Put screenshots in:

`docs/public/shots/`

VitePress treats this as a static asset directory, so pages can reference files with paths like `/shots/<filename>`.

## Suggested filenames

Use this set first. I can wire them directly into the site later:

| Filename | Purpose |
| --- | --- |
| `home-hero.png` | the single screenshot that best captures the overall product mood |
| `dashboard-library.png` | Library panel or primary list view |
| `dashboard-workspace.png` | Workspace status or management view |
| `dashboard-prompt-detail.png` | prompt detail or document detail view |
| `dashboard-review.png` | PR review or proposal review view |
| `dashboard-insights.png` | Trace, stats, or insights view |

## Suggested specs

- Prefer `png`
- Prefer widths between `1600px` and `2200px`
- For terminal captures, keep the full window boundary when possible
- Keep the same theme and font settings across the screenshot set
- Do not crop too aggressively; a little environment is usually better than a tiny fragment
