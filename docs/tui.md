# Archived Zig TUI

> **历史归档。** 本页不定义当前产品或运行架构。

The Zig TUI is not an active or supported product surface. Desktop is the
human-facing client. The former implementation and related historical code are
preserved only under `archive/zig-cli/`; they are outside active builds,
packaging, tests, releases, and documentation navigation.

See [Overview](/overview) for the current product surfaces.
